One funny text message from your future self, sent back to the present you — no setup, no context, just the message as it would arrive.

## Entry

> Hey, it's you from 2038. Stop Googling your symptoms at 2 a.m. Spoiler: it's the chair. Buy the good one — your back already filed the complaint.

## How it works

`main.ts` (Node.js stdlib only) writes the single text message to `/output/entry.txt`. The entry is exactly one line, under 200 characters.

## Run

```sh
node main.ts
cat /output/entry.txt
```
